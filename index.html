🔗 Connect to Google Calendar

To get started with full Google Calendar integration, you'll need to set up Google API credentials. This is a one-time setup that takes about 5-10 minutes.

Create a Google Cloud Project

Go to Google Cloud Console and create a new project

Enable Google Calendar API

In your project, search for "Google Calendar API" and enable it

Create OAuth 2.0 Credentials

Go to APIs & Services → Credentials → Create Credentials → OAuth client ID

Configure OAuth Consent Screen

Set it as "External" for testing, add your email as a test user

Add Authorized Origins

Add the domain where you'll host this app (or use http://localhost for testing)

💡 Quick Tip: For local testing, use "http://localhost:8000" as your authorized origin. You'll need to serve this file through a web server (not just open it directly).

Need help? Check out the Google Calendar API Quickstart Guide
