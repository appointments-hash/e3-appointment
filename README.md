# Appointment Manager Pro - Deployment Package

This folder is ready to deploy to Netlify or any web hosting service!

## What's Inside:
- **index.html** - Your Google Calendar integrated Appointment Manager Pro
- **GOOGLE_CALENDAR_SETUP.md** - Complete setup instructions

## Quick Deploy to Netlify:

1. Go to [netlify.com](https://netlify.com) and sign up (free)
2. Drag and drop THIS ENTIRE FOLDER to Netlify Drop
3. Get your live URL (e.g., https://your-app.netlify.app)
4. Follow the GOOGLE_CALENDAR_SETUP.md guide to get your Google Client ID
5. Enter your Client ID in the app and connect!

## Alternative: Deploy via Netlify Dashboard

1. Sign up at netlify.com
2. Click "Add new site" → "Deploy manually"
3. Drag this folder
4. Done!
